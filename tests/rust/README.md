
# Rust Tests

Les tests du moteur Rust seront développés
au fur et à mesure de l'évolution du projet.

Pour exécuter les tests Rust :

```bash
cargo test --manifest-path rust-engine/Cargo.toml
```

Les tests d'intégration couvriront :

- Sérialisation JSON.
- Communication avec Python.
- Gestion des erreurs.
- Traitement des événements.
